# 视频下载助手 V1

复制抖音、快手、哔哩哔哩、YouTube、Instagram、X、TikTok、小红书的视频分享链接，粘贴进来，解析后选清晰度下载无水印 / 高清视频。

技术路线：Kotlin + Chaquopy + yt-dlp（即 Grok 对话里推荐的“方案一”）。本项目是全新编写的源码，没有使用、复制或反编译原“视频下载鸟”的品牌、代码或安装包。

> ⚠️ **先说清楚：本机没有编出 APK。** 原因是沙箱环境限制（Gradle 守护进程无法启动，详见文末“构建状态”），不是代码问题。完整源码已全部写好，请按下面“云端构建”走 GitHub Actions 编出 APK。**在真机上安装使用之前，本 App 未经过真机验证。**

---

## V1 功能

- **粘贴链接解析**：输入框 + “粘贴”按钮；打开 App 自动检测剪贴板里的链接并填入；自动识别平台（抖音 / 快手 / 哔哩哔哩 / YouTube / Instagram / X / TikTok / 小红书 / 其他）。
- **解析结果**：显示标题、作者、时长、封面；列出可选清晰度（合并格式，如 1080p / 720p / 480p，另有“仅音频”），选一个再下载。
- **下载**：前台服务 + 通知栏进度条与百分比；下载失败可点“重试”；保存到手机 **下载 / VideoDownloader /** 文件夹，文件名取自视频标题（已清洗非法字符）。
- **历史记录**：本地保存（App 内部 `history.json`），点一条打开播放，长按可分享或删除记录。
- **接分享链接**：在别的 App 里分享视频链接时选“视频下载助手”，链接自动带过来。
- **权限**：联网、通知（Android 13+）、前台服务；Android 8–9 写公共下载目录需存储权限，Android 10+ 用 MediaStore，无需存储权限。不用 VPN、无障碍、Root、Shizuku。

## 怎么用

1. 在视频 App 里点“分享”→“复制链接”。
2. 打开本 App，链接会自动填入（或点“粘贴”），点“解析”。
3. 选清晰度，点“下载”，在通知栏看进度。
4. 下载完在手机“下载 / VideoDownloader /”里找视频，或在 App 的历史记录里打开。

## 云端构建（拿 APK 的步骤）

本地沙箱编不出 APK，请这样操作：

1. 在 GitHub 新建一个空仓库（例如 `video-downloader-app`，公开或私有均可）。
2. 把本项目整个文件夹的内容传上去（`git init` → `add` → `commit` → `push`，或直接在 GitHub 网页点“uploading an existing file”上传文件夹）。注意不要传 `local.properties`（本项目没有这个文件）。
3. 打开仓库的 **Actions** 标签页 → 左侧选 **Build APK** → 点 **Run workflow**（或 push 代码后自动跑）。
4. 等待运行完成（首次约 5–15 分钟：要下载 Android SDK、Gradle 依赖、Python 运行环境和 yt-dlp）。
5. 在那次运行的页面底部 **Artifacts** 里下载 `video-downloader-debug`，解压得到 `app-debug.apk`。
6. 把 APK 传到安卓手机，点安装即可（安装包约 40MB 以上，因为内置了 Python 运行环境和 yt-dlp；这是正常的）。

也可以在自己装好 Android Studio 的电脑上打开本项目，点运行即可；需要的版本：JDK 17、Gradle 8.7、Android SDK（API 34）。

## 安装后注意

- 首次下载时，Android 13+ 会弹窗问是否允许通知，点“允许”才能在通知栏看到下载进度。
- 只下载你有权保存的公开视频，不要下载、传播他人享有版权的付费内容；遵守各平台的使用规则。

## 已知限制（V1，如实说明）

- **部分平台需要登录**：抖音、快手、小红书等有时会要求登录或触发风控，解析失败时会提示“该链接需要登录才能查看”。V1 **不支持**导入 Cookie、扫码登录，这是 V2 再做的事，不要反复重试同一个链接。
- **清晰度上限**：只提供“视频 + 音频一体”的合并格式和“仅音频”。YouTube 等平台的 1080p 及以上通常是音视频分开的，需要 ffmpeg 合并，V1 暂不支持，所以解析后可能最高只到 720p，甚至只有音频可选。抖音 / 快手 / 小红书等平台的源文件本身就是合并格式，1080p 照常可选。
- **实测提醒**：2026-11-10 在电脑上用 yt-dlp 2026.10.26 实测解析 YouTube 公开视频成功，但只返回了 1 条音频格式，没有合并视频格式（YouTube 侧需要 JS 运行环境才能拿到完整格式列表，手机上没有）。也就是说 **YouTube 在 V1 里可能只能下音频**，抖音 / 快手 / B 站等平台不受这个影响（它们的源文件一般是单个合并文件）。
- **下不了的视频**：需要登录、付费、会员专享、私密或已被删除的视频都下不了。
- **各平台随时可能改版**导致解析失败，遇到这种情况一般是等 yt-dlp 更新版本，不代表 App 坏了。
- 每次解析和下载都要联网；APK 体积较大（约 40MB+）；无 iOS 版。

## 隐私

链接只发给视频网站本身做解析，不经过任何中转服务器；本 App 不收集账号、不上传你的链接和下载记录；下载的视频只存在你的手机本地。

## V2 计划

- 导入 Cookie / 扫码登录后下载需登录的视频
- 1080p+ 合并下载（内置 ffmpeg）
- 批量下载、下载到指定文件夹
